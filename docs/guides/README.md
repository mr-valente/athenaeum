# Operator guides

1. [Oracle infrastructure](1-oracle-infrastructure.md) — create or recover the cloud resources and establish SSH access.
2. [Host setup](2-host-setup.md) — prepare Ubuntu and start a new or recovered stack.
3. [Daily usage](3-daily-usage.md) — maintain the running system with `athenaeumctl`.
4. [Writing and arranging content](4-authoring.md) — edit pages, organize sections and lessons, and preview and publish Markdown.
5. [Backup and recovery](5-backup-and-recovery.md) — recovery drills, offsite copies and disaster recovery.

Use 1 and 2 when rebuilding after a disaster or creating an independent installation. They assume an Arch workstation and an Ubuntu 26.04 ARM VM. Keep private resource identifiers, keys, backup checksums, and image digests in your recovery notes, outside Git.

See the [documentation index](../README.md) for development and recovery references.
